# iPad Backend Project

군 복무 중 iPad로 백엔드 개발 공부

## 📝 프로젝트 소개
- Python + Flask를 이용한 REST API 개발
- 보안을 고려한 백엔드 설계 학습
- 6개월 학습 목표

## 🛠️ 기술 스택
- **언어**: Python
- **프레임워크**: Flask
- **데이터베이스**: SQLite
- **인증**: JWT
- **배포**: Replit

## 📚 학습 목표
- [ ] Flask 기초
- [ ] SQLite 연동
- [ ] JWT 인증
- [ ] REST API 설계
- [ ] 보안 개념 적용
